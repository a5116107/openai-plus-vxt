## 后续数据任务

- 优先补齐同一账号在同一国家切换多个 IP，以及同一 IP 跨多个账号的交叉单元；当前具体 IP 主效应仍是数据缺口。
- 以随机错位顺序复测 JP/IN 及探索国家，避免 sequence、周期与国家继续绑定。
