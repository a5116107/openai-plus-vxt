# 优惠/试用资格因素研究 SSOT

> 资格类型、证据等级、保持不变量和漂移处理统一见 [试用资格与多支付提链 SSOT](../trial-payment-probe/README.md)。本文件保留因素实验与统计细节。

## 1. 当前结论

截至 2026-07-30，已有实测能够证明 Auth、Checkout/优惠评估、Billing 可使用不同动态出口。参考环境汇总称累计 729 条逐次记录、58 个账号、37 个周期、20 个实验，其中明确资格结果 177 条（命中 94、未命中 83），明确结果命中率 53.1%；项目内尚未找到这 729 条逐次原始观测，因此该组数据作为“外部汇总待复算”，不再标记为独立可复现证据。

当前最强信号来自 Checkout 国家/路线：外部汇总的总体 94/177 为 53.1%（Wilson 95%CI 45.8%–60.3%）；JP 为 81/94、86.2%（77.8%–91.7%），IN 为 0/52（0%–6.9%）。11 个同时覆盖 JP 与 IN 的账号全部表现为 JP 更高，配对账号平均 JP 约 92.6%、IN 0%。因此“资格只跟随账号”的解释明显减弱，Checkout 国家/路线存在强稳定关联，但仍待逐条原始观测复算。

这仍不是永久因果规则：Checkout IP 共 160 个，只有 2 个 IP 覆盖多个账号，国家、IP、账号批次、执行顺序和周期尚未完全正交。26 个重复账号×国家单元只有 1 个出现结果变化，说明完全逐请求随机解释较弱；慢速灰度、账号×国家交互和未观测上游 cohort 仍可能存在。Auth 国家和 Billing 国家目前区间重叠较大，独立主效应证据不足。

任何国家排行榜都只是观测相关性。正式结论必须同时给出样本量、命中率、95% Wilson 区间、错误率、交叉对照和结论等级。

`0.0.33` 新增处理一致性门：计划国家与 Checkout 实际国家不一致、实际出口未验证、凭据失效或结果为请求错误时，该行仍保存用于错误率和漂移，但不进入资格率、因素主效应、匹配效应、覆盖矩阵或复测 cooldown。支付方式只有实际提交后才进入支付方式归因；Auth/Checkout/Billing 三段都与计划一致后才进入路由归因。

2026-07-30 最新真实小样本为 2 账号 × HK/JP 共 4 次：通用前置出口健康，实际前置 IP 在检查时为 `95.40.46.144/HK`，但目标域 TLS 探针失败；4 次均为 `network-proxy`，明确资格结果 0、可归因样本 0、命中 0、有效终链 0。HK 的 Checkout 国家处理生效 2/2，JP 实际仍为 HK、处理未生效 0/2。该轮只证明质量门和错误隔离生效，不支持任何资格因素结论。

同日进一步诊断确认：白名单 API 新提取的 HK、JP、US、IN 节点曾分别同时通过 Cloudflare 与 ChatGPT trace，实际国家均与计划一致，证明 `10808 -> 短期国家节点 -> 目标域` 链路设计可行；节点约 10 分钟后失效。随后白名单 API 对当前动态来源 IP 返回未登记状态，账号网关在四个入口、四个国家均返回 502，因此当前阻塞属于供应节点生命周期与来源白名单，而不是资格逻辑。真实执行器已支持 `OPX_LIVE_FRONT_PROXY` 指定 HTTP/SOCKS 任意端口，并把同一端点同步到扩展代理总开关、front/exit1/exit2 与国家出口映射；严格模式在目标域不可达、国家错位或扩展健康检查不匹配时于账号实验前停止。

2026-08-09 当前环境复测：本地 `10808` 经 sing-box 的 Cloudflare 与 ChatGPT trace 均为 HTTP 200，实际国家同为 SG，说明该单一出口的目标域可达性已恢复；`7890` 未监听。隔离浏览器 profile 直连及经 SG 出口请求 Session 均返回 HTTP 403，账号和 access token 均不存在，因此未进入严格 1x1 账号实验。该结果只更新当前可达性边界，不覆盖历史 HK/JP/US/IN 短期节点证据，也不满足多国家或有效登录态验收。

此前两轮同批账号的 HK 严格复核共 24 次，其中明确结果 21、命中 0、请求错误 3；按明确结果计为 0/21，Wilson 95%CI 0%–15.5%。这些重复样本只说明该账号批次在对应时段与路线下未观察到资格，不能单独判定 HK 永久低概率，也不能区分账号与时段效应。

## 2. 研究问题与可证伪假设

| 假设 | 可观测信号 | 最小对照 |
| --- | --- | --- |
| H1 账号主效应 | 同一账号在多个出口仍稳定命中/不命中 | 每账号 >= 4 个出口，至少 10 个账号 |
| H2 国家主效应 | 不同账号在同一国家的命中率稳定高于其他国家 | 每国 >= 20 次，账号与时段平衡 |
| H3 出口 IP/ASN 主效应 | 同国家内不同 IP/ASN 的区间分离 | 每 IP/ASN >= 10 次，至少 2 个账号 |
| H4 阶段路由主效应 | Auth>Checkout>Billing 国家/IP 组合改变后命中率变化 | 每路由签名 >= 10 次 |
| H5 账号×出口交互 | 账号和出口单独接近，但组合差异显著 | 完整账号×出口交叉矩阵 |
| H6 支付方式/币种效应 | 相同账号与出口下，方式或币种改变结果 | 每方式 >= 10 次 |
| H7 时间/灰度效应 | 近期窗口相对历史基线发生显著变化 | 基线与近期各 >= 10 次 |
| H8 随机或未观测分配 | 已采变量无稳定主效应，重复实验仍有不可解释波动 | 总样本 >= 100 且交叉矩阵平衡 |

## 3. 因素字典

### 3.1 已采集并进入逐次观测

- 账号：匿名稳定 ID、来源、导入批次、账号存续小时数。
- 实验：任务、轮次、顺序、配置重试数、耗时。
- 地区：探测国家、bootstrap/promotion/provider 国家、Auth/Checkout/Billing 实际国家。
- 出口：三阶段 IP、ASN、colo、代理端点摘要、seed 摘要、是否验证、前置代理摘要。
- 网络：实际出口 IPv4/IPv6、ASN 组织、residential/hosting/unknown 粗分类、健康状态和延迟。
- 商品：plan、通道、支付方式、币种、金额提示、命中类型、检测到的支付方式。
- 客户端：插件版本、浏览器家族、语言、时区。
- 时间：时间戳、本地 4 小时时段、星期。
- 结果：hit/miss/error、错误分类、优惠/试用提示。
- 处理真实性：计划与实际三阶段国家、国家/路由/支付方式是否生效、归因有效性状态与逐条原因。

逐次观测不保存 access token，账号分析使用 `accountId`；导出 JSON 也不包含 token。

### 3.2 可由现有字段推导

- 三阶段路由签名：`AuthCountry>CheckoutCountry>BillingCountry`。
- 账号×国家、账号×Checkout 出口、国家×支付方式交互项。
- 账号年龄、国家/出口覆盖、重试错误率、价格和方式集合变化。
- IP 版本、ASN 粗粒度网络类别、近期与历史窗口差异。

### 3.3 上游或支付流程支持后继续补入

- 账号历史：既往订阅、既往试用、取消/退款、邀请或组织状态。
- 账号画像：注册国家、手机号国家、风控/信任分、上游实验 cohort。
- 支付画像：账单地址、卡 BIN 国家、钱包账户国家、processor entity、税区。
- 网络质量：IP 信誉、代理类型的可靠标签、DNS 出口、TLS/JA3、子网和自治域层级。
- 会话画像：Cookie 年龄、token 签发地区、session cohort、上游响应实验标头。
- 设备画像：UA 完整版本、设备指纹、屏幕、WebGL；只有在上游响应确实表现相关时再采集。

这些字段缺失时必须显示为“未观测”，不得用国家或 IP 代替解释。

## 4. 统计口径

1. 样本单位：一次完整的 `账号 × 探测国家` 优惠评估，成功、无资格和请求错误都各记一行。
2. 原始命中率：`hit / 全部观测`；同时展示错误数，避免把网络故障当作无资格。
3. 区间估计：二项比例使用 95% Wilson 区间；高命中排序优先比较区间下界，再比较原始命中率。
4. 因素证据：每组达到最小样本后比较组间差和区间重叠，输出不足/弱/中/强，不输出单点绝对结论。
5. 漂移：近期 7 天与此前 30 天基线比较；窗口不足时按时间前后半段比较。资格率和错误率需绝对变化 >= 15pp 且双比例 `|z| >= 1.64`。
6. 价格漂移：相同国家与币种的金额中位数变化 >= 10%，或 0 与非 0 状态改变。
7. 支付方式漂移：同一国家近期方式集合出现新增或移除。
8. 存储：默认保留最近 3000 条，配置范围 500–10000；统计报告、告警和建议由观测日志重建。
9. 资格率分母：只使用 `hit + miss` 的明确结果；请求错误单列为错误率，不再等价于无资格。
10. 协议一致性：套餐、分阶段模式、代理模式、支付方式、通道、插件版本和浏览器组成协议签名；主协议占比低于 80% 时结论降级。
11. 出口证据：Checkout 实际出口验证覆盖低于 80% 时，账号/国家/出口差异只保留为探索线索。
12. 最小可检测差异：看板展示当前样本量对应的近似 MDE；观察差异小于 MDE 时维持证据不足。
13. 规则纪元：全局资格率达到漂移阈值后自动定位最大变点，因素报告使用当前纪元，历史窗口仍用于漂移比较。
14. 匹配对照：国家效应按账号分层，账号效应按国家分层，具体 IP/ASN 按账号+国家分层，阶段路由按账号+探测国家分层，时间/顺序/重试按账号+国家分层。
15. 混杂审计：任意两变量达到 95% 确定性绑定时显示告警；国家与 IP 一一绑定时不得分别宣称主效应。
16. 统计功效：按双侧 alpha=0.05、power=0.80 估算检测 10/15/20pp 差异所需的每组和总样本，并显示剩余样本。
17. 重复稳定性：按账号×Checkout 国家统计稳定单元、变化单元和相邻结果转移率，用于区分逐请求随机、慢速漂移和稳定规则。
18. 处理有效性：只有 Checkout 实际国家与计划一致、出口已验证、凭据未失效且结果明确的观测进入国家/账号/IP归因；支付与路由按各自处理门继续收窄。
19. 覆盖真实性：请求错误和处理未生效的单元不增加矩阵样本，不触发 cooldown，也不满足证据门。

## 5. 实验设计

### 第一层：账号固定，轮换出口

同一账号按随机顺序测试至少 4 个国家/出口；下一账号使用不同顺序，抵消“越晚探测越容易失败”的顺序效应。

### 第二层：出口固定，轮换账号

同一 IP/ASN 上测试多个账号，账号来自不同注册批次；用于区分账号主效应和出口主效应。

### 第三层：阶段路由交叉

至少比较 `A>A>A`、`A>B>B`、`A>B>C` 三类 Auth/Checkout/Billing 路由。每个组合记录实际 IP，而不是只记录配置国家。

### 第四层：时间重复与保底探索

按小时/星期重复关键组合；高置信组承担主要流量，同时默认保留 20% 给未知、低样本和发生漂移的组。旧排行榜不得永久锁定国家。

### 设计约束

- 代理是浏览器进程级状态，当前有效并发固定为 1，防止阶段串线。
- 每轮随机/轮换顺序并记录 `sequence`，分析顺序和重试副作用。
- 同账号重复创建 Checkout 可能改变上游状态；需保留新账号批次作为对照。
- 国家、IP、ASN、支付方式和时段必须尽量正交；不平衡时只报告相关性。

### 可执行平衡排程

- 开启“平衡研究模式”后，任务以 `账号 × 出口国家` 单元为排程对象，高命中率筛选不参与研究矩阵裁剪。
- 每个账号使用错位国家顺序；下一轮继续旋转起点，降低账号顺序、国家顺序和运行时长的混杂。
- 研究模式忽略 `skipAccountAfterHit`，命中后继续完成剩余单元；普通轮询仍保留原早停行为。
- 排程器优先补样本最少的单元；同单元达到复测最小间隔前进入 cooldown，不重复消耗账号状态。
- 默认每单元目标 3 次、最小跨时段间隔 240 分钟、最低总样本 100；三项均可配置。
- 覆盖门同时检查完整矩阵、同账号多出口、同出口多账号、跨时段重复和总样本；未达标时账号、国家、出口、交互和随机解释统一为“证据不足”。

## 6. 自适应探测

- 高命中组：按 Wilson 下界优先，不以原始 100% 小样本直接晋级。
- 低样本组：未达到 `factorMinSamples` 时进入实验建议。
- 漂移组：告警后提升为 high/urgent，目标样本至少增加一个最小样本块。
- 受控对照缺口：缺少同账号跨国家、同账号同国家跨 IP 或同路由跨时段样本时，自动生成 high 优先级补样建议。
- 变量绑定缺口：国家×IP、账号×国家或国家×顺序达到混杂阈值时，自动生成 urgent/high 交叉实验建议。
- 未知国家：在高命中模式下仍按 `adaptiveExplorationPercent` 保留轮换名额。
- 健康失败：只剔除当前失败出口；新 seed、冷却恢复或规则漂移后可重新进入。

## 7. 结论输出规范

看板必须回答五件事：

1. 总样本、总体命中率和 95% 区间。
2. 账号、国家、出口、交互、时间各自的证据等级。
3. 哪些结论受样本不足或变量混杂限制。
4. 最近是否发生资格率、错误率、价格或支付方式漂移。
5. 下一轮应增加哪些组合及目标样本量。
6. 控制账号/国家后差异是否仍存在，以及国家与 IP 是否仍不可区分。
7. 检测 10/15/20pp 差异当前还差多少明确结果，重复结果的稳定率和转移率是多少。

看板同时展示协议一致性、Auth/Checkout/Billing 出口验证覆盖、明确结果比例、错误率、矩阵平衡度、最小可检测差异和规则纪元。只有质量门与平衡覆盖门同时满足，状态才从“相关性”提升为“稳定关联”；出现漂移时状态立即变为“规则漂移中”。

平衡实验区域还必须展示总单元、已覆盖、已完成、缺失/冷却单元、同账号多出口覆盖、同出口多账号覆盖、跨时段单元和总样本门槛。

正式对外表述示例：`US 观测命中率 42.0%，95%CI 28.1%–57.2%，n=43；在账号与时段尚未平衡前，该结果只支持国家相关性，不支持国家因果结论。`

## 8. 观测导入闭环

- 设置页提供“一键导入观测”，支持粘贴 JSON 或 CSV，不依赖手工修改浏览器存储。
- JSON 接受观测数组或 `{ "observations": [...] }`；导出文件使用 `schemaVersion: 2`，可直接重新导入。
- CSV 至少包含 `accountId`、`probeCountry`，支持 Auth/Checkout/Billing 的 country、IP、ASN、endpoint 和 verified 扁平字段。
- 导入模式支持 `merge` 与 `replace`。合并模式按观测 ID 去重，替换模式先清空因素观测，但不影响命中链接数据库。
- 导入结果返回 accepted、rejected、duplicates、total，并遵守 500–10000 条的配置存储上限。
- 每次导入后立即从观测重建因素报告、漂移告警、规则纪元、平衡矩阵和自适应建议，无需刷新或手工触发分析。
- 单条数据字段不合法时计入 rejected；合法记录继续写入，避免整批数据因个别坏行丢失。
