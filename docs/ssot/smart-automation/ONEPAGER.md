# 智能自动化一页纸

## 主目标
同账号多出口自动撞优惠/试用资格 → 命中链接入库 → 用健康度/命中率/支持支付方式自动收敛。

## 五段闭环
1. 环境接入：Register-Tool/前置10808 + 链式出口(TH/IN/JP/US)
2. 资源准备：账号token + 任务策略
3. 智能规划：健康剔除 + 高命中国家 + 方式推荐
4. 执行探测：代理切换 → checkout/UPL三阶段 → 判定/富化/入库
5. 反馈学习：stats/seed/method/runlog 驱动下一轮

## 两条业务链
- 探测链（主智能环）：token → 多国撞资格 → 链接资产
- 注册链（供给）：Auth 动态出口 → Checkout/优惠动态出口 → Billing 动态出口 → session/token → 供给探测链

## 三阶段出口原则
- 阶段进入时轮换，阶段内部固定
- 每个账号开启新 cycle
- 实际 IP/国家验证后才继续
- 可选强制 Auth、Checkout、Billing 三个 IP 互不相同

## 日常按钮顺序
本机链式默认 → 导入账号 → 健康检查 → 跑一轮看日志 → 应用推荐方式 → 启动定时
